# StutterCare AI: دليل التشغيل والإطلاق

## 0. مهم: تأكد إنك شغّال على النسخة الجديدة
1. فك الـ ZIP في فولدر **جديد** (مش فوق القديم).
2. انسخ ملف `backend/.env` القديم جوه فولدر `backend` الجديد.
3. اقفل التيرمنالين القديمين (Ctrl + C)، وشغّل من الفولدر الجديد (الخطوات تحت). لازم تعمل `npm install` في الفولدرين تاني.
4. علامة إنك على النسخة الجديدة: بتظهر شاشة **اختيار اللغة (العربية / English)** أول ما تفتح الموقع، وفي القايمة بتلاقي "تعلّم" و"تدريب المرآة".
5. اعمل تحديث كامل للمتصفح (Ctrl + Shift + R).

## 1. التشغيل المحلي
```powershell
# الباك اند
cd backend
npm install
copy .env.example .env      # واملأ القيم
npm run dev

# الفرونت (تيرمنال تاني)
cd stuttercare-ai
npm install
copy .env.example .env
npm run dev
```
افتح http://localhost:5173 في Chrome أو Edge. الاختبارات: `npm test` في كل فولدر.

> **لينك شغّال دايمًا من غير تيرمنال؟ اقرأ `DEPLOY-AR.md`.**

## 2. إرسال الـ OTP على الإيميل فعلًا
بدون إعدادات إيميل الكود بيظهر في تيرمنال الباك اند (للتجربة فقط). للإيميل الحقيقي استخدم **Brevo API** (الأفضل، وبيشتغل على الاستضافة المجانية):
```
BREVO_API_KEY=مفتاح_الـAPI
MAIL_FROM=StutterCare AI <بريد_الـSender_المؤكّد_في_Brevo>
```
أو SMTP (محليًا فقط، لأن Render المجاني بيمنعه):

**Brevo (الأنسب للإطلاق، فيه باقة مجانية يوميًا):**
1. أنشئ حسابًا على brevo.com، وأضف بريدك كـ Sender وأكّده.
2. من SMTP & API انسخ SMTP key.
3. في `backend/.env`:
```
SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_USER=بريد_تسجيل_الدخول_في_Brevo
SMTP_PASS=SMTP_key
MAIL_FROM=StutterCare AI <بريد_الـSender_المؤكّد>
```
**Gmail (للتجربة فقط، حدّه اليومي صغير):** فعّل التحقق بخطوتين، واعمل App Password، `SMTP_HOST=smtp.gmail.com` و `SMTP_PORT=587`.

بعد التعديل جرّب الإرسال من غير ما تسجّل حساب:
```powershell
cd backend
npm run test:mail -- بريدك@gmail.com
```
لو نجح هيكتب `Sent!` والرسالة توصل (وبص في Spam). لو فشل بيقولك السبب (باسورد غلط أو لا يوصل للسيرفر). وبعدها أعد تشغيل الباك اند. للإنتاج الجاد اربط نطاقك (SPF/DKIM) عشان الرسائل ما تروحش Spam.

## 3. الأدوار وإزاي بيتم الربط
- **الطفل/الكبير (patient):** من صفحة "ملاحظات الأخصائي" بيشوف **كود ربط من 8 رموز**.
- **ولي الأمر أو الأخصائي:** من لوحته يكتب الكود في "اربط مريضًا بالكود". الربط بيتم فقط بموافقة صاحب الكود، وهو يقدر يلغيه أو يغيّر الكود.
- ولي الأمر يقدر كمان **يضيف طفلًا** بنفسه (بإيميل وباسورد للطفل).
- الأخصائي بيشوف التقارير ويعدّل خطة التمارين ويكتب ملاحظات بتوصل للمريض.

## 4. لوحة المدير (مين دخل الموقع)
1. في `backend/.env` أضف `ADMIN_EMAIL` و `ADMIN_PASSWORD` (12 حرف أو أكتر).
2. شغّل `npm run seed:admin` مرة واحدة.
3. سجّل دخول بالحساب ده، وهتلاقي "لوحة المدير": عدد الحسابات، الجدد، النشطين، حسب النوع والمسار، وآخر المسجلين.
4. من نفس اللوحة تقدر **تفعّل Premium** لأي حساب بعد الدفع (30/90/365 يوم) أو تلغيه.

## 5. النسخة المدفوعة (Premium)
**عايزة كل حاجة مجانية؟** حطي `PREMIUM_ENABLED=false` في `backend/.env` (وفي Render ← Environment) وأعيدي تشغيل الباك اند. كل المميزات بتتفتح للكل وصفحة Premium بتختفي من القايمة. الكود بيفضل موجود لو عايزة ترجعيه (`true`).

- كل حساب جديد بياخد **تجربة مجانية 7 أيام** (غيّرها بـ `TRIAL_DAYS`).
- المدفوع: التقنيات المتقدمة، كل المحاكاة، لوحة التحليلات للكبار (تسجيل المواقف).
- الدفع حاليًا يدوي: المستخدم يحوّل (InstaPay / فودافون كاش)، يبعت الإثبات واتساب، وانت تفعّل من لوحة المدير. اضبط الأسعار والواتساب في `stuttercare-ai/.env` (`VITE_PRICE_MONTHLY`, `VITE_WHATSAPP`...).
- الدفع الأوتوماتيك (كروت وفودافون كاش وفوري) يتم عن طريق **Paymob**: محتاج حساب تاجر عندك، وبعدها نربط الـ checkout والـ webhook.

## 6. النشر
- الباك اند: Render أو Railway أو Fly.io. `NODE_ENV=production`، `CLIENT_URL=https://موقعك`، وباقي متغيرات `.env.example`. في Atlas اسمح بعنوان الاستضافة.
- الفرونت: `npm run build` وارفع `dist` على Cloudflare Pages أو Netlify، مع `VITE_API_URL=https://عنوان-الباك-اند`.
- بعد أول نشر لحسابات قديمة: `npm run migrate:verify-existing` مرة واحدة.

## 7. تثبيت الموقع على الموبايل
بعد نشر الموقع على https، من كروم على الأندرويد: القايمة ثم **Add to Home screen**، فيظهر كتطبيق بأيقونته.

## 8. قبل ما تفتح للأطفال
- فيه صفحة `/privacy` وصندوق موافقة في التسجيل (قالب جاهز). خلّي محامي يراجعها، وحط بريد التواصل في `VITE_CONTACT_EMAIL`. المستخدم يقدر يحذف حسابه من الإعدادات.
- التعرّف على الكلام بيتم في المتصفح (كروم/إيدج بيبعتوا الصوت لخدمتهم). التطبيق بيحفظ الدرجات فقط، مش الصوت. وضّح ده للأهل.
- أركان مدرب ذكاء اصطناعي، مش طبيب. خلّي أخصائي نطق مؤهل يراجع التمارين والدرجات قبل الإطلاق الواسع.
